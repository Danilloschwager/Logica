# 🧠 Lógica de Programação

Repositório dedicado ao estudo e prática de **lógica de programação**, com exercícios, exemplos e desafios para desenvolver o raciocínio lógico e a resolução de problemas.

---

## 🎯 Objetivo

Este projeto tem como finalidade:

- Fortalecer a base em lógica de programação  
- Desenvolver pensamento computacional  
- Praticar resolução de problemas  
- Servir como material de apoio para iniciantes  

A lógica é a habilidade mais importante para qualquer programador, independente da linguagem utilizada.

---

## 📚 Conteúdos

Neste repositório você encontrará exercícios envolvendo:

- 🔹 Estruturas sequenciais  
- 🔹 Condicionais (`if`, `else`, `switch`)  
- 🔹 Laços de repetição (`for`, `while`)  
- 🔹 Variáveis e tipos de dados  
- 🔹 Operadores lógicos e matemáticos  
- 🔹 Problemas práticos e desafios
